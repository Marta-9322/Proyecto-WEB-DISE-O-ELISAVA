# Registro de trabajo

Este archivo mantiene la continuidad del proyecto entre sesiones.

## Protocolo de trabajo

### Al comenzar cada sesión
1. Leer este archivo para recuperar el estado y los últimos acuerdos.
2. Leer `personalidad.md` para respetar la identidad, el tono y la experiencia buscada.
3. Leer `criterio.md` para aplicar los criterios de diseño y desarrollo.
4. Revisar los archivos del proyecto que estén relacionados con la tarea del día.
5. Si hay decisiones pendientes o información insuficiente, consultarlo antes de asumirla.

### Al terminar cada sesión
1. Actualizar este archivo con la fecha y un resumen de lo trabajado.
2. Anotar los archivos creados o modificados.
3. Registrar decisiones confirmadas, cuestiones pendientes y el siguiente paso recomendado.
4. No indicar como terminado algo que no se haya comprobado.

**Nota:** el registro se actualiza al cerrar cada sesión de trabajo en la que se realicen cambios. No se actualiza automáticamente en segundo plano.
